# 轻练 V1.1 · 75天自动进阶训练

## 课程规则
- 共5个难度，每个难度15个完成的训练日，共75天。
- 难度1–3：不分级，每天3次。
- 难度4、5：每个难度的A、B、C、D、E级各持续1、2、3、4、5个训练日；难度4每天3次，难度5每天2次。
- 达到当前训练日要求次数才算完成这一天。下一训练日需在下一个自然日开始；漏练或未满额不会跳级。
- 上传视频时选择对应难度等级。只有与当前课程阶段匹配的视频能用于当前进度打卡。
- V1的历史记录与视频仍留在同一个 IndexedDB 数据库 `qinglian-kegel-v1` 中。旧版打卡不计入新版课程进度，避免未经确认的自动升级。旧版「难度一/二/三」视频可自动识别。

## 使用说明
- 电脑：解压后使用较新的 Chrome/Edge/Safari 打开 index.html；浏览器需允许本地存储。
- iPhone：不推荐直接从「文件」预览 HTML 长期使用；建议把静态网页部署至 HTTPS，然后 Safari 打开并添加到主屏幕。当前 ZIP 不是一个现成的互联网网址，也未部署。
- 重要：浏览器存储按照**域名、协议与来源**隔离。要延续 V1 的视频与打卡，必须在**同一设备、同一个浏览器、同一网页来源（相同 URL origin）**打开升级版。更换 file:// 路径、使用新的 HTTPS 域名、或者切换 App 浏览器，可能看不到原数据库。升级前先在 V1 导出备份，再到 V1.1 恢复。恢复会替换当前数据。
- 视频仅保存在设备的 IndexedDB 中，不会上传云端。推荐定期从「我的」中导出备份，备份包括视频文件，可能较大。
- 当前版本无账号、无推送提醒、无云同步，不会自动检测是否真实完成训练；需要手动点击打卡。
